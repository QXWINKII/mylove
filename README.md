# Для моей королевы ❤️

Персональный статический сайт-сюрприз для GitHub Pages.

## Уже настроено

- Обращение: **Моя королева**
- Подпись: **от Муси**
- Встреча: **29.10.2026 в 00:45, МСК**
- Видео уже находится в `assets/video.mp4`
- Визуальный стиль: ночной, интимный, тёмный, кинематографичный

## Изменение текста и даты

Открой `script.js`. Все основные персональные данные находятся в самом начале внутри `CONFIG`.

```js
const CONFIG = {
  meetingDate: "2026-10-29T00:45:00+03:00",
  videoUrl: "assets/video.mp4",
  messages: { ... },
  text: { ... }
};
```

Остальной код менять не требуется.

## GitHub Pages

1. Создай новый GitHub-репозиторий.
2. Загрузи `index.html`, `style.css`, `script.js`, `README.md` и папку `assets`.
3. Открой **Settings → Pages**.
4. Выбери **Deploy from a branch**.
5. Branch: `main`, Folder: `/ (root)`.
6. Сохрани настройки.
7. Используй полученную GitHub Pages ссылку для QR-кода.

Сайт полностью статический: React, Next.js, backend, база данных и авторизация не используются.
